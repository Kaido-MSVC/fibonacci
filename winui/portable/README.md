# 費波那契數列計算器 1.0.1

Windows x64 免安裝版。請先完整解壓縮，再執行 `FibonacciWinUI.exe`。移動程式時請保留整個資料夾。本套件隨附 .NET 11.0.0 與 WinUI 3 執行階段。

1. 輸入 0 到 1,000,000 之間的整數。
2. 按 Enter 或「計算」。結果超過 4,096 位時，可按「上一頁」和「下一頁」瀏覽。
3. 按「複製結果」可將完整數字複製到剪貼簿。
